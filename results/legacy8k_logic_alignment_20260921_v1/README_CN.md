# 旧80.85%方法恢复及原100K同目标复核

2026-09-21。原图的已保存6468/8000结果已逐行复算；随后仅对原100K seed20260713，在完全相同的8000目标上实际执行88000个候选的本机推理。没有重新生成目标、训练、EMX或服务器操作。

## 旧图的实际逻辑

1. 模型是 `real10k_center15ghz_seed20260711`，不是原100K：来源10000行，实际train/validation/test为7871/1227/902。F=10→256→256→256→4，I=4→256→256→256→10，GELU。
2. 原8000目标来自保存的application8k帧：Lp和Ls均0.5–1.5 nH，|k|=0.5–0.8，0.67≤Ls/Lp≤1.5。seed20260824、14000个centered-LHS提案按不依赖模型响应的比例门限取前8000条。此次只读取原CSV，未重抽样。
3. 固定每条Lp/Ls/|k|，逐个输入整数Q=10,…,20，I及原decoder得到11个几何候选，再由该模型冻结F预测四指标。没有EM在此步骤，也没有局部优化。
4. 对每候选计算 `score=sqrt(mean(((proxy-[Lp,Ls,Q,|k|])/[2.5,2.5,20,0.8])**2))`，取最小值；精确平分时取较低Q。四项双侧偏差都计入；既不最大化Q，也不把Q作为下限。这里不是四项相对百分比误差的平均。
5. 选完候选再按 `abs(proxy-target)/target` 判断四项是否同时≤10%。6468/8000=80.85%（旧图显示80.8%）；单项命中7254/7620/7977/6967。失败不替补，分母不改。

## 为什么还不能称同一种训练方法

旧模型的保存训练合同为对称declared-range MSE，geometry anchor=.01，独立sigmoid训练包络decoder；F/I各1200更新。原100K则是不同非对称层宽、hard-feasible decoder，Q损失仅惩罚未达到Qtarget+2的部分；选checkpoint时Q≥target即可。此次只改变外部扫描评价，不改变这套已训练权重。

因此“按旧逻辑”必须区分：**外部扫描/选候选/命中统计已按原逻辑执行；原100K训练目标尚未改成旧对称目标，也没有重训。**若继续开发训练，应另存新版本，使响应训练与validation的Q语义同为对称目标，不可只改图注或测试函数。不能擅自移除当前几何/制造约束来追求代理分数，也不能用已观察的8000或10000成绩反复选模。

原旧trainer的绑定SHA为1288e8f5…9ef4a，本地现存同路径源码SHA不匹配；训练合同、权重、normalizer和可加载decoder已恢复，但源码级逐步训练精确复现仍未证实。详细来源及UNKNOWN见LEGACY_TRAINING_AUDIT.json/md。
